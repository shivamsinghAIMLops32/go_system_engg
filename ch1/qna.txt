Why does go run still need compilation?
go needs compilation for converting the program into machine code so it can get executed.

What's the difference between an executable file and a running process?
excutable file is an set of instructions that the operating system can execute, while a running process is the actual execution of those instructions.

Why does Go need a runtime if it already compiles to machine code?
Go needs a runtime to manage memory,stack,thread,go routines,hea memory,garbage collection.
